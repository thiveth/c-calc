# Simple C Calculator

A command-line calculator written in C.

Catches most if not all errors that could possibly be passed into stdin

##  Compile
gcc main.c -o calc

## Run
./calc

## Clone
git clone https://github.com/thiveth/c-calc
cd c-calc
make
./calc

# Features
- Add, subtract, multiply, divide
- Input validation
- Can handle division by 0
